Διαίσθηση & Θεωρία (Για Αρχάριους)

Τα προβλήματα CSP (Constraint Satisfaction Problems) αφορούν μια πολύ απλή ιδέα: «Αντί να γράψεις έναν αλγόριθμο που βρίσκει τη λύση, απλώς περιέγραψε τους κανόνες και άφησε τον υπολογιστή να τη βρει.»

1. Τι είναι το CSP; (Η αναλογία του Sudoku)

Σκέψου ένα Sudoku. Δεν γράφεις κώδικα που ψάχνει αριθμούς. Απλώς λες:
• Μεταβλητές: Τα 81 τετραγωνάκια (τι πρέπει να συμπληρωθεί).
• Πεδία: Κάθε τετραγωνάκι παίρνει τιμές από το 1 έως το 9.
• Περιορισμοί: «Όχι ίδιοι αριθμοί στην ίδια σειρά, στήλη ή κουτάκι 3x3».
Ο υπολογιστής παίρνει αυτή την περιγραφή και βρίσκει τη λύση μόνος του.

2. Γιατί ΔΕΝ γράφουμε κώδικα στην εξέταση;

Στις εξετάσεις ζητείται μόνο η μαθηματική μοντελοποίηση, όχι η υλοποίηση.
• Χρησιμοποιούμε καθαρή μαθηματική γλώσσα (Σ, ∀, ≤, ≥, ∈) για να περιγράψουμε τις μεταβλητές, τα πεδία, τους περιορισμούς και το κόστος.
• Οποιοσδήποτε κώδικας (π.χ. Prolog) μηδενίζεται!

🚦

Διάβασε πρώτα αυτό

⚠️ ΚΩΔΙΚΑΣ = 0 ΜΟΝΑΔΕΣ

Η εκφώνηση λέει ρητά: «Δεν ζητείται υλοποίηση. Κώδικας στην απάντηση δεν θα βαθμολογηθεί.» Γράψε μαθηματικό φορμαλισμό, όχι Prolog/ECLiPSe. Σύμβολα Σ, ∀, ≤, ∈ — όχι :-.

💡 Πάντα οι ίδιες 4 επικεφαλίδες

Δομή την απάντηση ακριβώς έτσι — οι διορθωτές ψάχνουν αυτές τις 4 λέξεις:

  1. Μεταβλητές (variables)
  2. Πεδία τιμών (domains)
  3. Περιορισμοί (constraints)
  4. Συνάρτηση κόστους / αντικειμενική (objective)
🧠 Μνημονικό: «Μ-Π-Π-Κ»

Μεταβλητές → Πεδία → Περιορισμοί → Κόστος. Θυμήσου τη φράση «Με Ποιά Πράγματα Κερδίζω;».

Και η μία ιδέα που τα ενώνει όλα: «διάλεξε με 0/1 · μέτρα με Σ · βελτιστοποίησε με min/max». Αν την κρατήσεις, στήνεις οποιοδήποτε πρόβλημα.

🧱

Το Universal Template

Σχεδόν κάθε πρόβλημα «διάλεξε υποσύνολο / ανάθεσε ώστε να βελτιστοποιηθεί κάτι» γράφεται με δυαδικές μεταβλητές απόφασης 0/1:

⚡ Σκελετός
Μεταβλητές:   xi ∈ {0,1},   i = 1…n   // xi=1 ⟺ «διαλέγω/αναθέτω το i»

Πεδία:   D(xi) = {0, 1}

Περιορισμοί:   Σ (γραμμικοί συνδυασμοί xi)   { = , ≤ , ≥ }   (όριο)

Κόστος:   min / max   Σi ci·xi
🧠 Το μυστικό της Γενίκευσης (Από τα Ελληνικά στα Μαθηματικά)

Για να λύσεις ένα εντελώς νέο πρόβλημα, μην ψάχνεις να θυμηθείς παλιές λύσεις. Κάνε την εξής "αυτόματη μετάφραση" από κείμενο σε μαθηματικά:

  • Βήμα 1 (Μεταβλητές): Βρες το "Τι πρέπει να αποφασίσω;". Π.χ. "Ποια πτήση να διαλέξω;" → Μεταβλητή xi. "Ποιον υπάλληλο e να βάλω στην ημέρα d;" → Μεταβλητή Se,d. Φτιάξε μια μεταβλητή για κάθε ανεξάρτητη επιλογή.
  • Βήμα 2 (Πεδία): Αν η επιλογή είναι Ναι/Όχι (την επιλέγω ή όχι;), το πεδίο είναι {0,1}. Αν η επιλογή είναι "ποια κατάσταση/βάρδια", το πεδίο είναι {Μ, Ε, Ν, R}.
  • Βήμα 3 (Περιορισμοί): Πάρε κάθε πρόταση της εκφώνησης και μετάφρασέ την:
    • Η λέξη "ακριβώς ένα" (π.χ. κάθε εργάτης σε μία βάρδια) → Το άθροισμα (Σ) ισούται με 1.
    • Η λέξη "τουλάχιστον ένα" (π.χ. τουλάχιστον ένας γιατρός) → Το άθροισμα (Σ) είναι ≥ 1.
    • Η φράση "όχι πάνω από X" ή "χωρητικότητα" → Το άθροισμα (Σ) με βάρη είναι ≤ X.
  • Βήμα 4 (Κόστος): Βρες τις λέξεις ελάχιστο/μέγιστο, φθηνότερο/ακριβότερο στην εκφώνηση. Γράψε απλώς min ή max μπροστά από το συνολικό άθροισμα (Σ) του κόστους.
📝 Η πιο συχνή σύγχυση: Περιορισμός ≠ Κόστος

Περιορισμός = κάτι που ΠΡΕΠΕΙ να ισχύει· αν δεν ισχύει, η λύση είναι άκυρη. Γράφεται με =, ≤, ≥.

Κόστος / αντικειμενική = κάτι που ΘΕΛΟΥΜΕ όσο γίνεται καλύτερο· καμία τιμή του δεν κάνει τη λύση άκυρη — απλώς χειρότερη. Γράφεται με min/max.

Γρήγορος έλεγχος: «χωρητικότητα ≤», «τουλάχιστον ≥», «ακριβώς =» → περιορισμός. «φθηνότερο», «μέγιστη αξία», «λιγότερες βάρδιες» → κόστος. Αν μια φράση μπορεί να «παραβιαστεί» χωρίς να χαλάσει η λύση, είναι κόστος· αλλιώς περιορισμός.

📝 Reification (για το MAX-SAT)

Όταν θες να μετρήσεις πόσοι περιορισμοί ισχύουν, βάλε μια δυαδική sj που «αντικατοπτρίζει» αν ισχύει ο περιορισμός j (reified constraint). Στην ECLiPSe αυτή η δυνατότητα λέγεται reification — η χρήσιμη «έξτρα» δυνατότητα που ρωτάει το 2022Β.

Και τα 5 Παλιά Θέματα — Λυμένα

🧭 Πώς να διαχειριστείς το Θέμα 2 (το πιο «ασφαλές» — γέμισε 4 κουτιά)

Δεν χρειάζεται έμπνευση. Χρειάζεται να γεμίσεις 4 κουτιά. Κάνε ΑΥΤΟ:

  1. Γράψε στο χαρτί τις 4 επικεφαλίδες Μ-Π-Π-Κ, με κενό κάτω από κάθε μία.
  2. Μεταβλητές: «τι αποφασίζω;» → μία 0/1 για κάθε επιλογή (ή xij για «βάζω το i στο j»).
  3. Πεδία: {0,1} (ή το σύνολο καταστάσεων, π.χ. {M,E,N,R}).
  4. Περιορισμοί: πάρε κάθε πρόταση της εκφώνησης και κάν' την ανισότητα με Σ (δες τον πίνακα μετάφρασης πιο πάνω).
  5. Κόστος: βρες το «ελάχιστο/μέγιστο…» και γράψε min / max Σ.

Καθόλου κώδικας. Αν γράψεις τα 4 κουτιά με σύμβολα (Σ, ∀, ≤), έχεις ήδη πάρει τις περισσότερες μονάδες.

💡 Αποκωδικοποίηση Όρων για Αρχάριους (Newbie Guide)

Αν βλέπεις τη μοντελοποίηση CSP πρώτη φορά, σκέψου τη σαν κανόνες για Sudoku:

  • CSP (Πρόβλημα Ικανοποίησης Περιορισμών): Αντί να γράψουμε κώδικα που λύνει ένα πρόβλημα, απλώς περιγράφουμε μαθηματικά τους κανόνες του. Προσοχή: Κώδικας Prolog = 0 μονάδες. Γράφουμε μόνο μαθηματικό φορμαλισμό (Σ, ∀, ≤, ≥, ∈).
  • Μεταβλητές (Variables): Τι αποφάσεις πρέπει να πάρουμε.
    • Δυαδικές (0/1): xi = 1 αν επιλέξουμε το i, 0 αν το απορρίψουμε (π.χ. Knapsack, Set Cover).
    • Ανάθεσης (xij): xij = 1 αν το αντικείμενο i πάει στη θέση/σακίδιο j.
    • Κατάστασης: Se,d ∈ {M, E, N, R} για τη βάρδια του υπαλλήλου e την ημέρα d.
  • Πεδία (Domains): Οι επιτρεπτές τιμές για κάθε μεταβλητή (π.χ. {0, 1} ή {M, E, N, R}).
  • Περιορισμοί (Constraints): Οι κανόνες της εκφώνησης μεταφρασμένοι σε μαθηματικές εξισώσεις/ανισότητες.
    • Exact Cover (ακριβώς ένα): Σ xi = 1.
    • Set Cover (τουλάχιστον ένα): Σ xi ≥ 1.
    • Χωρητικότητα/Όριο πόρου: Σ Wi·xi ≤ C.
  • Κόστος (Objective Function): Αυτό που θέλουμε να μεγιστοποιήσουμε (max) ή να ελαχιστοποιήσουμε (min) (π.χ. min Σ Ci·xi).
  • Reification (Αντανάκλαση Περιορισμού): Μια δυαδική μεταβλητή-διακόπτης sj ∈ {0,1} που παίρνει την τιμή 1 αν ισχύει ο j-οστός περιορισμός, και 0 αν παραβιάζεται. Μας βοηθά να μετράμε πόσους κανόνες ικανοποιήσαμε (π.χ. στο MAX-SAT).
📄 2023 Α — Πτήσεις: διαμέριση (exact cover), ελάχιστο κόστος

N πτήσεις, M συνδυασμοί Pi (υποσύνολα πτήσεων) με κόστος Ci. Διάλεξε συνδυασμούς ξένους μεταξύ τους που καλύπτουν ακριβώς όλες τις πτήσεις, με ελάχιστο κόστος.

Πλήρης λύση
Μεταβλητές: xi ∈ {0,1}, i=1…M  // xi=1 ⟺ διαλέγω τον συνδυασμό Pi

Πεδία: {0,1}

Περιορισμοί (exact cover):
για κάθε πτήση j ∈ {1…N}:   Σi : j ∈ Pi xi = 1
// κάθε πτήση καλύπτεται από ακριβώς έναν επιλεγμένο συνδυασμό → «ξένοι» + «καλύπτουν ακριβώς»

Κόστος:   min Σi=1M Ci·xi

Στο παράδειγμα η βέλτιστη {{1,5},{2},{3,4}} έχει κόστος 5+3+4=12. ✔

📄 2023 Β — Πτήσεις: κάλυψη (set cover), ελάχιστο κόστος

Ίδιο σκηνικό, αλλά οι συνδυασμοί όχι κατ' ανάγκη ξένοι: κάθε πτήση να καλύπτεται τουλάχιστον μία φορά, ελάχιστο κόστος.

📝 Μοναδική διαφορά από το 2023Α

Αλλάζει μόνο ο περιορισμός: = 1 γίνεται ≥ 1. Όλα τα άλλα ίδια.

Πλήρης λύση
Μεταβλητές: xi ∈ {0,1}, i=1…M

Πεδία: {0,1}

Περιορισμοί (κάλυψη): για κάθε πτήση j:   Σi : j ∈ Pi xi ≥ 1

Κόστος:   min Σi=1M Ci·xi

Βέλτιστη {{1,2,3},{2,4,5}} κόστος 5+6=11. ✔

📄 2021 Α — Πολλαπλό σακίδιο (multiple knapsack)

N αντικείμενα (βάρος Wi, αξία Vi), K σακίδια με χωρητικότητες Cj. Βάλε αντικείμενα σε σακίδια χωρίς υπέρβαση χωρητικότητας, μεγιστοποιώντας τη συνολική αξία.

Πλήρης λύση
Μεταβλητές: xij ∈ {0,1}, i=1…N, j=1…K  // xij=1 ⟺ αντικείμενο i στο σακίδιο j

Πεδία: {0,1}

Περιορισμοί:
κάθε αντικείμενο το πολύ σε ένα σακίδιο:   Σj=1K xij ≤ 1  (∀ i)
χωρητικότητα κάθε σακιδίου:   Σi=1N Wi·xij ≤ Cj  (∀ j)

Κόστος:   max Σi Σj Vi·xij

Στιγμιότυπο: 10 αντικείμενα, K=3, C=(30,35,40) → ίδιες εξισώσεις με N=10, K=3.

📄 2022 Α — Πρόγραμμα βαρδιών (50 υπάλληλοι × 30 ημέρες)

Βάρδιες M/E/N/R. Κανόνες: κάθε μέρα ≥15 M, ≥10 E, ≥8 N· μετά από N (νύχτα) όχι M την επομένη· σε κάθε 7 συνεχόμενες μέρες ≥2 R. Πρότεινε και αντικειμενική συνάρτηση.

Πλήρης λύση
Μεταβλητές: Se,d για e=1…50, d=1…30  // η βάρδια του υπαλλήλου e την ημέρα d

Πεδία: Se,d ∈ { M, E, N, R }

Περιορισμοί:
(κάλυψη) ∀d:  |{e : Se,d=M}| ≥ 15,  |{e : Se,d=E}| ≥ 10,  |{e : Se,d=N}| ≥ 8
(νύχτα→όχι πρωί) ∀e, ∀d∈{1…29}:   ¬( Se,d=N ∧ Se,d+1=M )
(ανάπαυση) ∀e, ∀ παράθυρο w∈{1…24}:   |{ d ∈ [w, w+6] : Se,d=R }| ≥ 2

Αντικειμενική (πρόταση):   min  maxe |{ d : Se,d=N }|
// ελαχιστοποίησε τις πιο πολλές νυχτερινές ενός υπαλλήλου → δίκαιη κατανομή
📖 Πώς διάβασα την εκφώνηση (κάθε πρόταση → ένας περιορισμός)
  • Το |{e : Se,d=M}| διαβάζεται απλά «πόσοι υπάλληλοι έχουν πρωινό τη μέρα d» — ένα μέτρημα. Το «≥ 15» είναι ο κανόνας κάλυψης.
  • «μετά από νύχτα όχι πρωί» → απαγόρευσε τον συνδυασμό: ¬(Se,d=N ∧ Se,d+1=M).
  • «≥ 2 ρεπό σε κάθε 7 μέρες» → για κάθε «παράθυρο» 7 διαδοχικών ημερών, το πλήθος των R να είναι ≥ 2.

Εναλλακτική αντικειμενική: ελαχιστοποίηση συνολικών νυχτερινών Σe,d[Se,d=N], ή εξισορρόπηση φόρτου.

📄 2022 Β — MAX-SAT (μέγιστη ικανοποιησιμότητα)

Δοθείσας CNF (σύζευξη m προτάσεων-clauses), βρες ανάθεση true/false στα προτασιακά σύμβολα ώστε να αληθεύουν όσο το δυνατόν περισσότερες προτάσεις.

Πλήρης λύση
Μεταβλητές:
xk ∈ {0,1} για κάθε προτασιακό σύμβολο k=1…n  // 1=true
sj ∈ {0,1} για κάθε πρόταση (clause) j=1…m  // 1 ⟺ ικανοποιείται

Πεδία: {0,1}

Περιορισμοί (reification): για κάθε clause j με θετικά σύμβολα Posj και αρνημένα Negj:
sj ≤ Σk∈Posj xk + Σk∈Negj (1 − xk)
// sj μπορεί να είναι 1 μόνο αν τουλάχιστον ένα λεκτικό αληθεύει

Κόστος:   max Σj=1m sj

Εμπειρική ανάθεση (το ρωτάει): για τον δοσμένο τύπο, μια ανάθεση που ικανοποιεί 6/7 προτάσεις: π.χ. x1=T, x2=T, x3=T, x4=F (μόνο η (¬x1∨¬x2∨x3)… έλεγξε γρήγορα — αρκεί να βρεις 6).

Χρήσιμη δυνατότητα ECLiPSe (εκτός ic/branch&bound): reification — η αντανάκλαση της αλήθειας ενός περιορισμού σε δυαδική μεταβλητή sj.

➕ 2 ακόμα κλασικά μοτίβα CSP (για να καλύψεις ΟΛΟΝ τον χάρτη)

Τα 5 παραπάνω καλύπτουν: διαμέριση, κάλυψη, σακίδιο, χρονοπρογραμματισμό, MAX-SAT. Δύο ακόμη τύποι εμφανίζονται συχνά σε τέτοια θέματα — μάθε και αυτά και μπορείς να μοντελοποιήσεις οτιδήποτε.

📄 Μοτίβο — Χρωματισμός γράφου / χάρτη (ελάχιστα χρώματα)

Δίνεται γράφος (κόμβοι + ακμές). Χρωμάτισε κάθε κόμβο ώστε γειτονικοί κόμβοι να έχουν διαφορετικό χρώμα, με τα λιγότερα δυνατά χρώματα. (Κλασικό: χρωματισμός χάρτη χωρών.)

Πλήρης λύση
Μεταβλητές:
ci = χρώμα του κόμβου i, για κάθε κόμβο i=1…n
yk ∈ {0,1} = «χρησιμοποιείται το χρώμα k;», για k=1…K  // K = μέγιστα διαθέσιμα χρώματα

Πεδία: ci ∈ {1,…,K}  ·  yk ∈ {0,1}

Περιορισμοί:
(1) για κάθε ακμή (i,j):   ci ≠ cj  // γείτονες ≠ χρώμα
(2) σύνδεσε y με c: αν κάποιος κόμβος έχει χρώμα k, τότε yk=1  // (reification: yk = 1 ⟺ ∃i: ci=k)

Κόστος:   min Σk=1K yk  // ελαχιστοποίησε τα χρώματα που όντως χρησιμοποιείς
📖 Τρόπος σκέψης
  • Μεταβλητή = «τι αποφασίζω για κάθε κόμβο» → το χρώμα του. Πεδίο = το σύνολο των χρωμάτων.
  • Ο περιορισμός είναι «≠ μεταξύ γειτόνων» — μία ανισότητα ανά ακμή. Αυτό είναι όλο το «δίκτυο».
  • «Ελάχιστα χρώματα» = κόστος. Δεν μετράς απλώς πόσα χρώματα έχεις διαθέσιμα — μετράς πόσα πραγματικά εμφανίζονται, με τις βοηθητικές yk.
  • Εναλλακτική με δυαδικές: xik∈{0,1} «κόμβος i έχει χρώμα k», με Σkxik=1 (ένα χρώμα ανά κόμβο) και xik+xjk≤1 για κάθε ακμή (i,j) (γείτονες όχι ίδιο k).
📄 Μοτίβο — Ανάθεση εργασιών σε πράκτορες με χωρητικότητα

n εργασίες, m πράκτορες (μηχανές/άτομα). Κάθε εργασία i πάει σε ακριβώς έναν πράκτορα, χρησιμοποιεί πόρο wi· κάθε πράκτορας j έχει χωρητικότητα Cj. Κόστος cij ανά ανάθεση. Ελαχιστοποίησε το συνολικό κόστος.

Πλήρης λύση
Μεταβλητές:
xij ∈ {0,1} = «η εργασία i ανατίθεται στον πράκτορα j;»   i=1…n, j=1…m

Πεδία: {0,1}

Περιορισμοί:
(1) κάθε εργασία σε ΑΚΡΙΒΩΣ έναν πράκτορα:   Σj=1m xij = 1   ∀i
(2) χωρητικότητα κάθε πράκτορα:   Σi=1n wi·xij ≤ Cj   ∀j

Κόστος:   min Σi=1n Σj=1m cij·xij
📖 Τρόπος σκέψης
  • Δυαδικός πίνακας xij: «ποιος πάει πού». Κλασική μορφή όποτε «αναθέτεις Α σε Β».
  • «Ακριβώς ένας» → Σ = 1 ανά γραμμή (εργασία). Αν ήταν «το πολύ ένας» → ≤ 1.
  • «Χωρητικότητα» → ζυγισμένο άθροισμα ≤ όριο ανά στήλη (πράκτορα) — ίδιο μοτίβο με το σακίδιο.
  • Κόστος = διπλό άθροισμα cij·xij. Αν είχες «αξία» αντί «κόστος» → max αντί min.
📚 Το μοτίβο που είδες σε όλα
