Μοντελοποίηση CSP

Μεταβλητές, πεδία, περιορισμοί και μια συνάρτηση κόστους που πραγματικά ξεχωρίζει τις λύσεις. Με έμφαση στα min max, max − min και στο λάθος του Ιουνίου.

🧩

Τι ζητάει το Θέμα 2 και τι βαθμολογείται

Σου περιγράφουν ένα πρόβλημα ανάθεσης, επιλογής ή χρονοπρογραμματισμού. Γράφεις μεταβλητές, πεδία, περιορισμούς και, σχεδόν πάντα, συνάρτηση κόστους. Η εκφώνηση ζητάει «μαθηματική ακρίβεια» και περιορισμούς «άμεσα υλοποιήσιμους σε ECLiPSe». Κώδικας δεν βαθμολογείται.

Η δομή της απάντησης (πάντα ίδια)

  1. Δεδομένα: ονόμασε ό,τι δίνεται (N, K, Li, M, …).
  2. Μεταβλητές: τι αποφασίζει ο λύτης, με ερμηνεία σε μία φράση.
  3. Πεδία: πού παίρνει τιμές κάθε μεταβλητή.
  4. Περιορισμοί: ένας για κάθε κανόνα της εκφώνησης, με ∀ και Σ.
  5. Συνάρτηση κόστους: μία παράσταση των μεταβλητών και «min». Μία πρόταση αιτιολόγησης.

Τι κόστισε τον Ιούνιο

Το μοντέλο ήταν σωστό. Η συνάρτηση κόστους ήταν «ελαχιστοποίηση του συνολικού φόρτου». Όμως κάθε εργασία ανατίθεται ακριβώς μία φορά, άρα ο συνολικός φόρτος είναι πάντα Σ Li. Μια συνάρτηση που έχει την ίδια τιμή σε όλες τις εφικτές λύσεις δεν διαλέγει τίποτα. Η ενότητα «Συνάρτηση κόστους» λύνει ακριβώς αυτό.

⚠️ Κώδικας = 0 μονάδες

Γράψε με σύμβολα (∀, Σ, ∈, ≤, ≠, [·]). Μπορείς να προσθέσεις μία γραμμή «στην ECLiPSe αυτό γράφεται με …» ως σχόλιο, αλλά οι μονάδες είναι στο μαθηματικό μοντέλο.

Περιορισμοί: λεξικό μετάφρασης

Κάθε πρόταση της εκφώνησης γίνεται ένας περιορισμός. Το εργαλείο που τα ενώνει όλα είναι η αγκύλη [συνθήκη]: ισούται με 1 αν η συνθήκη ισχύει και 0 αλλιώς. Στην ECLiPSe αυτό είναι reified constraint (π.χ. B #= (X #= J)), άρα «άμεσα υλοποιήσιμο».

Η εκφώνηση λέειΓράφεις
«κάθε i σε ακριβώς έναν»Σj xij = 1 ∀i · ή αυτόματο με Xi ∈ {1..K}
«το πολύ σε έναν»Σj xij ≤ 1 ∀i · ή Xi ∈ {0..K}
«καλύπτει ακριβώς / ξένα μεταξύ τους»Σi : j∈Pi xi = 1 ∀j
«καλύπτει τουλάχιστον μία φορά»Σi : j∈Pi xi ≥ 1 ∀j
«χωρητικότητα / όριο φόρτου του j»Σi Li · [Xi = j] ≤ M ∀j · ή Σi Li xij ≤ M
«τουλάχιστον 15 την ημέρα d στη βάρδια M»Σe [Se,d = M] ≥ 15 ∀d
«όχι Α και αμέσως μετά Β»[Se,d = N] + [Se,d+1 = M] ≤ 1 ∀e, d
«σε κάθε 7 συνεχόμενες μέρες τουλάχιστον 2 ρεπό»Σt=dd+6 [Se,t = R] ≥ 2 ∀e, ∀d ∈ {1..24}
«δεν επιτρέπεται να συμπέσουν i και j»Ti ≠ Tj (για κάθε ζεύγος που συγκρούεται)
«όλα διαφορετικά»alldifferent(X1, …, Xn) · ισοδύναμα Xi ≠ Xj ∀i < j
«αν κάτι ισχύει, τότε …»[A] ≤ [B] (συνεπαγωγή σε 0/1)
«δεν επιτρέπονται δύο μη γειτονικοί»xu + xv ≤ 1 για κάθε (u,v) ∉ E
📝 Περιορισμός ή κόστος;

Ό,τι πρέπει να ισχύει (αλλιώς η λύση απορρίπτεται) είναι περιορισμός. Ό,τι θέλουμε όσο το δυνατόν καλύτερο είναι κόστος. «Δεν επιτρέπεται να υπερβαίνει το M» είναι περιορισμός. «Όσο πιο δίκαιη γίνεται» είναι κόστος.

Η συνάρτηση κόστους: εδώ χάθηκαν οι μονάδες

Η συνάρτηση κόστους είναι μία παράσταση των μεταβλητών που ο λύτης ελαχιστοποιεί. Πριν τη γράψεις στο γραπτό, πέρασέ τη από τέσσερις ελέγχους.

  1. Κατεύθυνση. Στην ECLiPSe το bb_min ελαχιστοποιεί. «Μεγιστοποίησε F» γράφεται «ελαχιστοποίησε −F». Στο γραπτό μπορείς να γράψεις max, αρκεί να είναι ξεκάθαρο.
  2. Έλεγχος σταθερότητας. Πάρε δύο πολύ διαφορετικές εφικτές λύσεις. Αν η συνάρτηση δίνει πάντα την ίδια τιμή, δεν διαλέγει τίποτα και είναι λάθος. Αυτό έγινε τον Ιούνιο.
  3. Έλεγχος νοήματος. Πάρε μια λύση που φανερά είναι καλύτερη (με τη λέξη της εκφώνησης) και έλεγξε ότι έχει μικρότερη τιμή. Για «δίκαιη»: η (8,6,6) πρέπει να «κερδίζει» την (8,8,4).
  4. Έλεγχος βοηθητικών μεταβλητών. Αν γράψεις Z ≥ Loadj για κάθε j, η Z είναι μόνο άνω φράγμα. Γίνεται ίση με το max μόνο επειδή την ελαχιστοποιείς. Με «max Z» θα ανέβαινε στο άπειρο.
⚠️ Γιατί το «min συνολικού φόρτου» δεν γίνεται να είναι σωστό

Με Xi ∈ {1..K} κάθε εργασία μετράει σε ακριβώς έναν εργαζόμενο, άρα:

Σj=1K Loadj  =  Σj Σi Li·[Xi = j]  =  Σi Li · Σj[Xi = j]  =  Σi Li · 1  =  σταθερά

Στο widget το βλέπεις: και οι 102 εφικτές αναθέσεις είναι «βέλτιστες» με αυτό το κριτήριο. Η δικαιοσύνη αφορά το πώς μοιράζεται το σύνολο, άρα χρειάζεται μέγεθος που μετράει διαφορές ανάμεσα στους φόρτους.

Πώς γράφεται «άμεσα υλοποιήσιμο» ένα max ή min

Τρόπος 1: έκφραση max/min

Max = max(Load1, …, LoadK)
Min = min(Load1, …, LoadK)
min  Max − Min

Η ECLiPSe (ic) δέχεται max/min σε εκφράσεις περιορισμών, και το ic_global έχει maxlist/2, minlist/2.

Τρόπος 2: βοηθητικές μεταβλητές

Zmax, Zmin ∈ {0..M}
Zmax ≥ Loadj   ∀j
Zmin ≤ Loadj   ∀j
min  Zmax − Zmin

Σωστό επειδή ελαχιστοποιείς: ο λύτης κατεβάζει το Zmax μέχρι το πραγματικό max και ανεβάζει το Zmin μέχρι το πραγματικό min.

🧠 Σε μία γραμμή

Μέτρα τη διαφορά, όχι το σύνολο. Αν το σύνολο είναι σταθερό, η δικαιοσύνη κρύβεται στο πόσο απέχουν μεταξύ τους τα μερίδια: max − min, ή τετράγωνα.

Ιούνιος 2026: η απάντηση όπως γράφεται στο γραπτό

N εργασίες, K εργαζόμενοι, φόρτος Li, κάθε εργασία σε ακριβώς έναν, κανείς πάνω από M. Ζητείται μοντέλο CSP και συνάρτηση κόστους για την πιο δίκαιη ισοκατανομή του φόρτου.

Μοντέλο Α (ακέραιες μεταβλητές ανάθεσης)

Δεδομένα: N εργασίες με φόρτους L1, …, LN· K εργαζόμενοι· μέγιστος φόρτος M.

Μεταβλητές: Xi, i = 1, …, N  // ο εργαζόμενος που αναλαμβάνει την εργασία i
Πεδία: Xi ∈ {1, …, K}
// ο «φόρτος του j» είναι παράσταση, όχι νέα μεταβλητή:
Loadj = Σi=1N Li · [Xi = j],   j = 1, …, K

Περιορισμοί:
(1) κάθε εργασία σε ακριβώς έναν εργαζόμενο: ισχύει από την ίδια τη μεταβλητή Xi (μία τιμή)
(2) Σi=1N Li · [Xi = j] ≤ M   ∀ j ∈ {1, …, K}

Συνάρτηση κόστους (ελαχιστοποίηση):
min   maxj Loadj − minj Loadj

Αιτιολόγηση (μία πρόταση στο γραπτό): ο συνολικός φόρτος Σj Loadj = Σi Li είναι ίδιος σε κάθε λύση, άρα η δικαιοσύνη μετριέται από το πόσο διαφέρουν οι φόρτοι· ελαχιστοποιώ τη διαφορά του πιο φορτωμένου από τον λιγότερο φορτωμένο.

Μοντέλο Β (δυαδικός πίνακας + βοηθητικές μεταβλητές)
Μεταβλητές: xij ∈ {0,1},   i = 1..N, j = 1..K  // 1 ⟺ η εργασία i πάει στον j
Zmax, Zmin ∈ {0, …, M}  // βοηθητικές για το εύρος

Περιορισμοί:
(1) Σj=1K xij = 1   ∀ i
(2) Σi=1N Li xij ≤ M   ∀ j
(3) Zmin ≤ Σi Li xij ≤ Zmax   ∀ j

Κόστος:  min   Zmax − Zmin
Εναλλακτικές συναρτήσεις κόστους που επίσης στέκουν
  • min maxj Loadj: κατεβάζει τον πιο φορτωμένο. Είναι το κλασικό «min max». Αν το γράψεις, πρόσθεσε ότι δεν ξεχωρίζει λύσεις με ίδιο μέγιστο (π.χ. (8,8,4) και (8,6,6)).
  • min Σj Loadj²: ισοδύναμο με ελαχιστοποίηση της διασποράς, αφού το άθροισμα είναι σταθερό.
  • min Σj |K·Loadj − Σi Li|: απόσταση κάθε μεριδίου από το ιδανικό ίσο μερίδιο.
Σκίτσο σε ECLiPSe (προαιρετικό, για να «δεις» ότι είναι υλοποιήσιμο)
% ΣΚΙΤΣΟ σε ECLiPSe (ΔΕΝ ζητείται στο γραπτό, μόνο για διαίσθηση) :- lib(ic), lib(ic_global), lib(branch_and_bound). balance(Ls, K, M, Xs, Cost) :- length(Ls, N), length(Xs, N), Xs :: 1..K, ( for(J, 1, K), foreach(Load, Loads), param(Ls, Xs, M) do ( foreach(L, Ls), foreach(X, Xs), foreach(T, Ts), param(J) do T #= L * (X #= J) ), % [X = J] ως reified περιορισμός Load #= sum(Ts), Load #=< M ), maxlist(Loads, Max), minlist(Loads, Min), Cost #= Max - Min, bb_min(labeling(Xs), Cost, _).

Το μοντέλο ελέγχθηκε με λύτη περιορισμών στο στιγμιότυπο (6,6,4,2,2), K = 3, M = 10: με εύρος δίνει φόρτους (8,6,6), με min max δίνει (8,8,4), με συνολικό φόρτο δίνει την πρώτη τυχαία εφικτή.

Λυμένα παλιά θέματα

Τα παρακάτω είναι γραμμένα όπως θα έπρεπε να είναι στο γραπτό. Περισσότερα, με «δοκίμασε πρώτα», στην Προπόνηση Θέματος 2.

2020 Α · εργασίες σε σχισμές, «να ολοκληρώνεται το συντομότερο» (min max)

Εργασίες μίας μονάδας χρόνου με σύνολα πόρων Rt. Δύο εργασίες με κοινό πόρο δεν εκτελούνται μαζί. Βέλτιστο πρόγραμμα = ολοκληρώνεται όσο πιο νωρίς γίνεται.

Μοντέλο + στιγμιότυπο
Μεταβλητές: Tt, για κάθε εργασία t  // η σχισμή στην οποία εκτελείται η t
Πεδία: Tt ∈ {1, …, n}  // n = πλήθος εργασιών· ποτέ δεν χρειάζονται περισσότερες σχισμές
Περιορισμοί: Ts ≠ Tt για κάθε ζεύγος s, t με Rs ∩ Rt ≠ ∅
Κόστος: min maxt Tt  // η τελευταία χρησιμοποιούμενη σχισμή (makespan)

Στιγμιότυπο: T1, …, T5 ∈ {1..5}
T1≠T2 (a) · T1≠T3 (b) · T1≠T4 (c) · T2≠T3 (d) · T3≠T4 (e) · T3≠T5 (f)
min max(T1, …, T5) → βέλτιστο 3 (π.χ. t1/1, t2/2, t3/3, t4/2, t5/1)

Προσοχή: το «συντομότερο» είναι το max των σχισμών. Το Σ Tt μετράει κάτι άλλο (μέσο χρόνο ολοκλήρωσης) και δεν είναι αυτό που ζητήθηκε.

2023 Α (και 2019 Α, 2009 Α) · πτήσεις: επιλογή ξένων συνδυασμών (set partitioning)
Μοντέλο + στιγμιότυπο
Μεταβλητές: xi ∈ {0,1}, i = 1..M  // 1 ⟺ επιλέγω τον συνδυασμό Pi
Περιορισμοί: Σi : j ∈ Pi xi = 1   ∀ j ∈ {1..N}  // κάθε πτήση ακριβώς μία φορά ⇒ ξένοι και πλήρης κάλυψη
Κόστος: min Σi=1M Ci xi

min 6x1+7x2+5x3+3x4+4x5+8x6+6x7   → βέλτιστο x3=x4=x5=1, κόστος 12

Σi : j ∈ Pi xi ≥ 1   ∀ j

2021 Α · πολλαπλό σακίδιο
Μοντέλο + στιγμιότυπο
Μεταβλητές: Xi ∈ {0, 1, …, K}, i = 1..N  // σε ποιο σακίδιο μπαίνει το i· 0 = σε κανένα
Περιορισμοί: Σi=1N Wi · [Xi = j] ≤ Cj   ∀ j ∈ {1..K}
Κόστος: max Σi Vi · [Xi ≠ 0]   ⟺   min Σi Vi · [Xi = 0]  // η αξία που μένει έξω

Στιγμιότυπο (2021 Α): N = 10, K = 3, (C1,C2,C3) = (30, 35, 40), W = (6,15,22,14,15,18,6,14,34,40), V = (12,10,32,19,17,11,22,13,42,7)
6[X1=j] + 15[X2=j] + 22[X3=j] + 14[X4=j] + 15[X5=j] + 18[X6=j] + 6[X7=j] + 14[X8=j] + 34[X9=j] + 40[X10=j] ≤ Cj, j = 1,2,3
βέλτιστη αξία 144 (συνολική 185, μένουν έξω 41)

Με δυαδικό πίνακα: xij ∈ {0,1}, Σj xij ≤ 1, Σi Wi xij ≤ Cj, max Σij Vi xij. Εδώ το «σταθερό σύνολο» βοηθάει: max(αξία μέσα) = 185 − min(αξία έξω).

2022 Α / 2017 Β / 2015 Β / 2008 Α · βάρδιες 50 υπαλλήλων × 30 ημέρες
Μοντέλο

Πεδία: Se,d ∈ {M, E, N, R}
Περιορισμοί:
(1) Σe [Se,d = M] ≥ 15,   Σe [Se,d = E] ≥ 10,   Σe [Se,d = N] ≥ 8   ∀ d
