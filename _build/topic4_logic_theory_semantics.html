1. Κατηγορηματική Λογική Πρώτης Τάξης

Η Κατηγορηματική Λογική Πρώτης Τάξης (First-Order Logic, FOL) είναι το μαθηματικό υπόβαθρο της Prolog. Θα ορίσουμε αυστηρά τα συντακτικά της στοιχεία.

1.1 Τα Τρία Σύνολα Συμβόλων

Μια γλώσσα πρώτης τάξης αποτελείται από τρία ξεχωριστά σύνολα:

P = σύνολο κατηγορημάτων (predicates)
F = σύνολο συναρτησιακών συμβόλων (function symbols)
V = σύνολο μεταβλητών (variables)

Σε κάθε κατηγόρημα ή συναρτησιακό σύμβολο αντιστοιχεί ένας ακέραιος n ≥ 0 που λέγεται βαθμός ή τάξη (arity). Γράφουμε k/n για κατηγόρημα/σύμβολο k με arity n.

📝 Σταθερές

Τα συναρτησιακά σύμβολα τάξης 0 (δηλαδή χωρίς ορίσματα) αναφέρονται και ως σταθερές (constants). Π.χ. socrates/0 ή 1/0 είναι σταθερές.

1.2 Ορισμός Όρου (Term)

⚡ Αναδρομικός Ορισμός: ΟΡΟΣ
  1. Αν x ∈ V, τότε το x είναι όρος
  2. Αν c/0 ∈ F, τότε το c είναι όρος (σταθερά)
  3. Αν f/n ∈ F (n > 0) και t₁, t₂, …, tₙ είναι όροι, τότε το f(t₁, t₂, …, tₙ) είναι όρος
% Παραδείγματα όρων με f/1, g/1, a/0, x ∈ V a % σταθερά x % μεταβλητή f(x) % f εφαρμοσμένο σε x g(f(x)) % σύνθεση f(g(a)) % σύνθεση

1.3 Ορισμός Ατομικού Τύπου / Ατόμου (Atom)

⚡ Αναδρομικός Ορισμός: ΑΤΟΜΟ
  1. Αν p/0 ∈ P, τότε το p είναι άτομο
  2. Αν p/n ∈ P (n > 0) και t₁, t₂, …, tₙ είναι όροι, τότε το p(t₁, t₂, …, tₙ) είναι άτομο
🧠 Όρος vs Άτομο — Η Κρίσιμη Διάκριση
  • Όρος = κάτι που είναι (π.χ. αντικείμενο, αριθμός). Δεν έχει τιμή αλήθειας.
  • Άτομο = κάτι που μπορεί να αληθεύει (π.χ. σχέση, ιδιότητα). Έχει τιμή true/false.

Διαφορά: parent(tom, bob) είναι άτομο (true ή false). tom και bob είναι όροι (αντικείμενα).

2. Καλοσχηματισμένοι Τύποι (WFF) & Ποσοδείκτες

2.1 Λογικά Συνδετικά

Με τα ακόλουθα συνδετικά (connectives) κατασκευάζουμε πιο σύνθετους τύπους από άτομα:

ΣύμβολοΌνομαΑγγλικάΔιαβάζεται
¬άρνησηnegation"όχι"
∧σύζευξηconjunction"και"
∨διάζευξηdisjunction"ή"
→συνεπαγωγήimplication"αν ... τότε ..."
↔ισοδυναμίαequivalence"αν και μόνο αν"
∀καθολικόςuniversal quantifier"για κάθε"
∃υπαρξιακόςexistential quantifier"υπάρχει"

2.2 Ορισμός WFF (Well-Formed Formula)

⚡ Αναδρομικός Ορισμός: WFF
  1. Αν Α είναι άτομο, τότε το Α είναι τύπος (atomic formula)
  2. Αν F και G είναι τύποι, τότε και τα (¬F), (F∧G), (F∨G), (F→G), (F↔G) είναι τύποι
  3. Αν F είναι τύπος και x ∈ V, τότε και τα (∀x F) και (∃x F) είναι τύποι
% Παραδείγματα τύπων με x,y ∈ V, p/2, q/1, r/1 ∈ P, a/0, f/1, g/1 ∈ F ∀x ∃y (p(x, y) → q(x)) ¬ ∃x (p(x, a) ∧ q(f(x))) ∀x (p(x, g(x)) ← q(x) ∧ ¬r(x))
📝 Ιεραρχία Προτεραιότητας

Για να μειώνουμε παρενθέσεις, υπονοούμε ιεραρχία:

¬ > ∀, ∃ > ∧ > ∨ > → > ↔

Έτσι το ∀x p(x) ∧ q(x) → r(x) διαβάζεται ως ((∀x p(x)) ∧ q(x)) → r(x).

2.3 Εμβέλεια (Scope) και Δεσμευμένες/Ελεύθερες Μεταβλητές

⚡ Ορισμοί
  • Εμβέλεια (scope) ενός ποσοδείκτη ∀x ή ∃x σε τύπο ∀x F είναι ο τύπος F.
  • Δεσμευμένη εμφάνιση (bound) μεταβλητής x είναι μια εμφάνιση είτε αμέσως μετά ποσοδείκτη, είτε μέσα στην εμβέλεια ποσοδείκτη που ποσοτικοποιεί αυτή τη μεταβλητή.
  • Ελεύθερη εμφάνιση (free) είναι κάθε άλλη.
  • Κλειστός τύπος (closed formula) = δεν περιέχει ελεύθερες εμφανίσεις μεταβλητών.
📚 Παράδειγμα Εξετάσεων

Στον τύπο: ∃x (p(x, y) ∧ q(x))

  • Πρώτη x (αμέσως μετά ∃): δεσμευμένη
  • Δεύτερη x (μέσα σε p(x, y)): δεσμευμένη (μέσα σε scope του ∃x)
  • Τρίτη x (μέσα σε q(x)): δεσμευμένη
  • Η y: ελεύθερη

Άρα ο τύπος ∃x (p(x, y) ∧ q(x)) δεν είναι κλειστός. Αντίθετα, ο ∀y ∃x (p(x, y) ∧ q(x)) είναι κλειστός.

3. Λεκτικά, Προτάσεις, και Horn Clauses

3.1 Λεκτικό (Literal)

⚡ Ορισμός: ΛΕΚΤΙΚΟ

Ένα λεκτικό (literal) είναι είτε ένα άτομο, είτε η άρνηση ενός ατόμου.

% Παραδείγματα λεκτικών p(a) % θετικό λεκτικό ¬p(a) % αρνητικό λεκτικό q(x, f(y)) % θετικό λεκτικό ¬r(z) % αρνητικό λεκτικό

3.2 Πρόταση (Clause)

⚡ Ορισμός: ΠΡΟΤΑΣΗ

Μια πρόταση (clause) είναι ένας τύπος της μορφής:

∀x₁ ∀x₂ … ∀xₛ (L₁ ∨ L₂ ∨ … ∨ Lₘ)

όπου τα Lᵢ είναι λεκτικά και τα xⱼ είναι όλες οι μεταβλητές που εμφανίζονται στα λεκτικά.

Δηλαδή: καθολική ποσοτικοποίηση μιας διάζευξης λεκτικών.

3.3 Εναλλακτική Γραφή — Implication Form

Αν χωρίσουμε τα λεκτικά μιας πρότασης σε θετικά Aᵢ και αρνητικά ¬Bⱼ:

(A₁ ∨ … ∨ A_k ∨ ¬B₁ ∨ … ∨ ¬B_n)
⇕
A₁, …, A_k ← B₁, …, B_n

Το αριστερό μέλος (Aᵢ) λέγεται κεφαλή (head), το δεξί (Bⱼ) σώμα (body).

3.4 Κατηγοριοποίηση Προτάσεων

k (θετικά)n (αρνητικά)ΌνομαΜορφή
k = 1n ≥ 0Οριστική (Definite)A ← B₁, …, B_n
k = 1n = 0Μοναδιαία (Unit) / ΓεγονόςA ←
k = 0n ≥ 1Οριστικός Στόχος (Goal)← B₁, …, B_n
k = 0n = 0Κενή Πρόταση (□)←

3.5 Πρόταση Horn

⚡ Ορισμός: ΠΡΟΤΑΣΗ HORN

Μια πρόταση Horn είναι είτε οριστική πρόταση είτε οριστικός στόχος. Δηλαδή πρόταση με το πολύ ένα θετικό λεκτικό.

💡 Γιατί η Prolog περιορίζεται σε Horn;

Οι προτάσεις Horn έχουν μια ζωτική ιδιότητα: το ελάχιστο μοντέλο ενός συνόλου Horn προτάσεων υπάρχει και είναι μοναδικό. Επιπλέον, η SLD-ανάλυση είναι πλήρης για Horn προτάσεις. Όλη η μαγεία της Prolog στηρίζεται σε αυτό.

🧠 Μνημονικός: Από Πρόταση Horn σε Prolog
ΛογικήProlog
A ←A. (γεγονός)
A ← B₁, …, B_nA :- B₁, …, B_n. (κανόνας)
← B₁, …, B_n?- B₁, …, B_n. (ερώτηση)

3.6 Οριστικό Πρόγραμμα

⚡ Ορισμός

Ένα οριστικό πρόγραμμα (definite program) είναι ένα σύνολο οριστικών προτάσεων. Αυτό είναι ακριβώς το είδος προγράμματος που μπορεί να γράψει η Prolog.

4. Μοντελοθεωρητική Σημασιολογία & Herbrand

Η μοντελοθεωρητική σημασιολογία (model-theoretic semantics) δίνει νόημα σε ένα πρόγραμμα μέσω μοντέλων — ερμηνείες όπου το πρόγραμμα αληθεύει.

4.1 Πλήρως Αποτιμημένοι (Ground) Όροι

⚡ Ορισμός

Ένας όρος ή τύπος που δεν περιέχει μεταβλητές λέγεται πλήρως αποτιμημένος (ground).

4.2 Σύμπαν Herbrand (U_L)

⚡ Ορισμός: HERBRAND UNIVERSE

Δοθείσης γλώσσας L, το σύμπαν Herbrand U_L είναι το σύνολο όλων των ground όρων που κατασκευάζονται χρησιμοποιώντας τα σύμβολα της L (συμπεριλαμβανομένων σταθερών).

Αν δεν υπάρχει σταθερά στη γλώσσα, εισάγουμε μια αυθαίρετη (π.χ. a) ώστε το U_L να μην είναι κενό.

📚 Παράδειγμα Υπολογισμού U_L

Έστω L με σύμβολα: f/1, a/0, p/1. Τότε:

U_L = { a, f(a), f(f(a)), f(f(f(a))), … }  =  άπειρο

Με σύμβολα μόνο a/0, b/0, c/0, p/2 (χωρίς συναρτησιακά > 0):

U_L = { a, b, c }  (πεπερασμένο)

4.3 Βάση Herbrand (B_L)

⚡ Ορισμός: HERBRAND BASE

Η βάση Herbrand B_L είναι το σύνολο όλων των ground ατόμων με κατηγορήματα της L και ορίσματα από το U_L.

📚 Παράδειγμα (συνέχεια)

Με L έχοντας: a/0, b/0, c/0, p/1, q/1, r/1:

U_L = { a, b, c }
B_L = { p(a), p(b), p(c), q(a), q(b), q(c), r(a), r(b), r(c) }

4.4 Ερμηνεία Herbrand

⚡ Ορισμός

Μια ερμηνεία Herbrand (Herbrand interpretation) είναι ένα υποσύνολο Ι ⊆ B_L. Διαισθητικά: τα άτομα που "αληθεύουν" σύμφωνα με την Ι.

% Για B_L = {p(a), p(b), p(c), q(a), q(b), q(c), r(a), r(b), r(c)} % μία ερμηνεία I μπορεί να είναι: I = { p(a), p(c), q(c), r(b) }

4.5 Τιμή Αλήθειας ενός Κλειστού Τύπου σε μια Ερμηνεία

Δοθείσης ερμηνείας Ι, ένας κλειστός τύπος F αληθεύει στην Ι σύμφωνα με αναδρομικούς κανόνες:

  1. Αν F = A (ground άτομο), τότε αληθεύει iff Α ∈ Ι
  2. Αν F = ¬G, τότε αληθεύει iff G δεν αληθεύει στην Ι
  3. Αν F = G ∧ H, τότε αληθεύει iff και τα δύο G, H αληθεύουν
  4. Αν F = G ∨ H, τότε αληθεύει iff τουλάχιστον ένα από G, H αληθεύει
  5. Αν F = G → H, τότε αληθεύει iff (G δεν αληθεύει) ή (H αληθεύει)
  6. Αν F = G ↔ H, τότε αληθεύει iff (G και H έχουν ίδια τιμή)
  7. Αν F = ∀x G, τότε αληθεύει iff για όλα τα d ∈ U_L, το G[x/d] αληθεύει
  8. Αν F = ∃x G, τότε αληθεύει iff υπάρχει d ∈ U_L τέτοιο ώστε το G[x/d] αληθεύει

4.6 Μοντέλο Herbrand

⚡ Ορισμός

Μια ερμηνεία Ι λέγεται μοντέλο Herbrand (Herbrand model) ενός συνόλου τύπων S, αν κάθε τύπος του S αληθεύει στην Ι.

4.7 Ελάχιστο Μοντέλο Herbrand (M_P)

🎓 Θεώρημα (Van Emden & Kowalski, 1976)

Αν P είναι οριστικό πρόγραμμα, τότε η τομή όλων των μοντέλων Herbrand του P είναι κι αυτή μοντέλο.

Αυτή η τομή λέγεται ελάχιστο μοντέλο Herbrand (least Herbrand model), συμβολίζεται M_P, και ταυτίζεται με:

M_P = { A ∈ B_L  |  P ⊨ A }

(όλα τα ground άτομα που είναι λογικές συνέπειες του P)

4.8 Πλήρες Παράδειγμα Υπολογισμού M_P

📚 Δουλειά Εξετάσεων

Δίνεται το οριστικό πρόγραμμα P:

p(x) ← q(x) q(x) ← r(x) p(a) ← q(b) ← r(c) ←

Βήμα 1: Υπολογισμός U_L — Σύμβολα: a, b, c, p/1, q/1, r/1. Δεν υπάρχουν συναρτησιακά τάξης > 0.

U_L = { a, b, c }

Βήμα 2: Υπολογισμός B_L

B_L = { p(a), p(b), p(c), q(a), q(b), q(c), r(a), r(b), r(c) }

Βήμα 3: Ποια άτομα είναι λογικές συνέπειες;

  • p(a): άμεσο γεγονός ✓
  • q(b): άμεσο γεγονός ✓
  • r(c): άμεσο γεγονός ✓
  • q(c): από q(x) ← r(x) και r(c) ✓
  • p(c): από p(x) ← q(x) και q(c) ✓
  • p(b): από p(x) ← q(x) και q(b) ✓

Άρα:

M_P = { p(a), p(b), p(c), q(b), q(c), r(c) }
⚠️ Δεν είναι όλα ground άτομα στο M_P

Τα q(a), r(a), r(b) δεν ανήκουν στο M_P γιατί δεν αποδεικνύονται από το πρόγραμμα. Αυτό είναι το "Closed World Assumption" — ό,τι δεν αποδεικνύεται είναι ψευδές.

5. Σημασιολογία Σταθερού Σημείου (Fixpoint)

Η μοντελοθεωρητική σημασιολογία μας λέει τι είναι το M_P, αλλά όχι πώς να το υπολογίσουμε. Η σημασιολογία σταθερού σημείου δίνει κατασκευαστικό τρόπο.

5.1 Ο Τελεστής T_P

⚡ Ορισμός: ΤΕΛΕΣΤΗΣ T_P

Δοθέντος οριστικού προγράμματος P, ορίζουμε τον τελεστή T_P ως:

T_P: 2B_L → 2B_L

T_P(I) = { A ∈ B_L | A ← A₁, …, Aₙ είναι
πλήρως αποτιμημένο στιγμιότυπο πρότασης του P
και { A₁, …, Aₙ } ⊆ I }

Σε ανθρώπινη γλώσσα: "το T_P(Ι) είναι όλα τα άτομα που μπορούν να αποδειχθούν σε ένα βήμα ξεκινώντας από αυτά που έχουμε στο Ι."

5.2 Ελάχιστο Σταθερό Σημείο (Least Fixpoint)

Ένα σταθερό σημείο (fixpoint) του T_P είναι μια ερμηνεία Ι τέτοια ώστε T_P(Ι) = Ι.

🎓 Θεώρημα Knaster-Tarski (εφαρμοσμένο)

Επειδή ο T_P είναι μονότονος και συνεχής, έχει ελάχιστο σταθερό σημείο, το οποίο υπολογίζεται ως:

lfp(T_P) = T_P↑ω = ⋃ { T_Pn(∅) : n ≥ 0 }

Δηλαδή: ξεκινάς από το κενό σύνολο και εφαρμόζεις το T_P επανειλημμένα.

5.3 Πλήρης Υπολογισμός με Επαναλήψεις

📚 Υπολογισμός lfp(T_P) — Το ίδιο πρόγραμμα όπως πριν

P:

p(x) ← q(x) q(x) ← r(x) p(a) ← q(b) ← r(c) ←

Ξεκινάμε από Ι₀ = ∅ και εφαρμόζουμε το T_P:

ΒήμαΣύνολοΝέα άτομα
T_P(∅) { p(a), q(b), r(c) } + p(a), q(b), r(c)
(από τα γεγονότα — δεν χρειάζονται συνθήκες)
T_P²(∅) { p(a), q(b), r(c), p(b), q(c) } + p(b) (από p(x)←q(x) και q(b))
+ q(c) (από q(x)←r(x) και r(c))
T_P³(∅) { p(a), q(b), r(c), p(b), q(c), p(c) } + p(c) (από p(x)←q(x) και q(c))
T_P⁴(∅) { p(a), q(b), r(c), p(b), q(c), p(c) } — (καμία αλλαγή = σταθερό σημείο!)

Άρα:

lfp(T_P) = { p(a), p(b), p(c), q(b), q(c), r(c) } = M_P ✓
💡 Πώς ξέρω ότι έφτασα σε σταθερό σημείο;

Όταν T_Pn+1(∅) = T_Pn(∅) — δηλαδή δεν προστίθεται κανένα νέο άτομο. Σταμάτα και το αποτέλεσμα είναι το M_P.

🎓 Πρώτη Ισοδυναμία
M_P = lfp(T_P)

Η μοντελοθεωρητική και η fixpoint σημασιολογία παράγουν το ίδιο αποτέλεσμα.

6. Επιχειρησιακή Σημασιολογία: SLD-Ανάλυση

Η επιχειρησιακή σημασιολογία αντιστοιχεί στην πραγματική εκτέλεση: η Prolog εφαρμόζει επαναλαμβανόμενα έναν κανόνα συμπερασμού — την SLD-ανάλυση.

6.1 Αντικατάσταση (Substitution)

⚡ Ορισμός

Μια αντικατάσταση θ είναι πεπερασμένο σύνολο της μορφής:

θ = { v₁/t₁, v₂/t₂, …, vₙ/tₙ }

όπου τα vᵢ είναι διαφορετικές μεταβλητές και τα tᵢ είναι όροι διαφορετικοί από τα αντίστοιχα vᵢ.

% Παραδείγματα αντικαταστάσεων θ = { x/a, y/f(b) } % x αντικαθίσταται με a, y με f(b) σ = { x/y, z/g(x) } % x→y, z→g(x) ε = { } % κενή αντικατάσταση

6.2 Στιγμιότυπο (Instance)

⚡ Ορισμός

Αν Ε είναι όρος ή τύπος και θ αντικατάσταση, το Εθ προκύπτει αντικαθιστώντας ταυτόχρονα κάθε εμφάνιση vᵢ με το tᵢ. Λέγεται στιγμιότυπο του Ε.

% Έστω E = p(x, f(y)) και θ = { x/a, y/b } Eθ = p(a, f(b))

6.3 Παραλλαγή (Variant)

⚡ Ορισμός

Το Ε λέγεται παραλλαγή του F αν υπάρχουν αντικαταστάσεις θ, σ τέτοιες ώστε E = Fθ και F = Eσ.

Διαισθητικά: ίδια δομή, διαφορετικά ονόματα μεταβλητών.

6.4 Σύνθεση Αντικαταστάσεων

Αν θ = {u₁/s₁, …, uₘ/sₘ} και σ = {v₁/t₁, …, vₙ/tₙ}, η σύνθεση θσ είναι αυτό που προκύπτει:

  1. Σχηματίζω {u₁/s₁σ, …, uₘ/sₘσ, v₁/t₁, …, vₙ/tₙ}
  2. Διαγράφω uᵢ/sᵢσ όταν uᵢ = sᵢσ
  3. Διαγράφω vⱼ/tⱼ όταν vⱼ ∈ {u₁, …, uₘ}

6.5 Ενοποιητής και mgu

⚡ Ορισμοί

Έστω S = {E₁, …, Eₙ} σύνολο όρων ή ατόμων.

  • Ενοποιητής (unifier): μια αντικατάσταση θ τέτοια ώστε Sθ είναι μονοσύνολο (δηλαδή E₁θ = E₂θ = … = Eₙθ).
  • Γενικότερος ενοποιητής (mgu): ενοποιητής θ τέτοιος ώστε για κάθε άλλο ενοποιητή σ, υπάρχει γ με σ = θγ.
  • Ενοποίηση: η διαδικασία υπολογισμού του mgu ενός συνόλου.
% Παράδειγμα S = { p(x, b), p(a, y) } % Ενοποιητής: θ = { x/a, y/b } % Sθ = { p(a, b) } — μονοσύνολο ✓ % Είναι mgu γιατί κάθε άλλος ενοποιητής (π.χ. {x/a, y/b, z/c}) προκύπτει από αυτόν.

6.6 Ο Κανόνας Συμπερασμού SLD

⚡ Ορισμός: ΚΑΝΟΝΑΣ SLD

Έστω στόχος G = ← A₁, …, Aₘ, …, Aₖ και πρόταση C = A ← B₁, …, B_q.

Αν θ είναι mgu των Aₘ και Α, τότε ο νέος στόχος G' που παράγεται (is derived) από τα G και C είναι:

G' = ← (A₁, …, A_{m-1}, B₁, …, B_q, A_{m+1}, …, A_k) θ
G = ← A₁, …, Aₘ, …, Aₖ
Αρχικός στόχος: ζητάμε να αποδείξουμε όλα τα Aᵢ.
Επιλέγω Aₘ (κάποιο)
Συνήθως Prolog επιλέγει το πρώτο (αριστερότερο).
Βρίσκω πρόταση A ← B₁, …, B_q
Όπου η κεφαλή Α ενοποιείται με Aₘ μέσω θ.
Αντικαθιστώ Aₘ με B₁, …, B_q
Το σώμα της πρότασης γίνεται νέοι υπο-στόχοι.
Εφαρμόζω θ σε όλα
Η αντικατάσταση διαδίδεται σε όλους τους νέους και υπάρχοντες στόχους.

6.7 SLD-Απόρριψη και Σύνολο Επιτυχίας

⚡ Ορισμοί
  • SLD-απόρριψη (SLD-refutation) του P ∪ {G}: μια ακολουθία εφαρμογών του κανόνα SLD που καταλήγει στην κενή πρόταση □.
  • Σύνολο Επιτυχίας SS(P): το σύνολο των ground ατόμων A τέτοιων ώστε υπάρχει SLD-απόρριψη του P ∪ {←A}.

7. Η Ισοδυναμία των Τριών Σημασιολογιών

Έχουμε ορίσει τρεις φαινομενικά διαφορετικές προσεγγίσεις στη σημασιολογία:

  • M_P — μοντελοθεωρητική: ελάχιστο μοντέλο Herbrand
  • lfp(T_P) — fixpoint: ελάχιστο σταθερό σημείο του τελεστή T_P
  • SS(P) — επιχειρησιακή: σύνολο επιτυχίας SLD-ανάλυσης
🎓 Θεμελιώδες Θεώρημα Λογικού Προγραμματισμού

Για κάθε οριστικό πρόγραμμα P:

M_P
=
lfp(T_P)
=
SS(P)

Οι τρεις σημασιολογίες είναι ισοδύναμες.

💡 Γιατί είναι σπουδαίο

Αυτή η ισοδυναμία είναι ορθότητα και πληρότητα της SLD-ανάλυσης. Σημαίνει ότι ό,τι αποδεικνύει η Prolog (SS) είναι λογικά αληθές (M_P), και κάθε λογική συνέπεια αποδεικνύεται.

8. Λογικός Προγραμματισμός με Περιορισμούς (CLP)

Ο Λογικός Προγραμματισμός με Περιορισμούς (Constraint Logic Programming, CLP) είναι επέκταση της Prolog που επιτρέπει δηλωτική και αποδοτική αντιμετώπιση προβλημάτων ικανοποίησης περιορισμών (CSPs).

8.1 Generate-and-Test vs Constrain-and-Generate

❌ Generate-and-Test

Γέννηση όλων δυνατών συνδυασμών, μετά έλεγχος αν ισχύουν οι περιορισμοί.

Εκθετικά αργό για μεγάλα προβλήματα.

✓ Constrain-and-Generate

Διατύπωση περιορισμών πριν, εφαρμογή τους κατά τη γέννηση τιμών.

Κουρεύει αμέσως αδύνατους κλάδους.

8.2 Μεθοδολογία CLP

  1. Όρισε μεταβλητές και τα πεδία τους (π.χ. X :: 1..10)
  2. Διατύπωσε περιορισμούς (π.χ. X #> Y, X+Y #= 5)
  3. Μη-ντετερμινιστική γέννηση τιμών για εύρεση λύσης

8.3 N-Βασίλισσες σε ECLiPSe

Η ECLiPSe είναι κλασική γλώσσα CLP. Λύνει τις N-βασίλισσες αποδοτικά:

:- lib(ic). nqueens(N, Solution) :- length(Solution, N), Solution :: 1..N, % κάθε στήλη μεταξύ 1..N constrain(Solution), % επιβολή περιορισμών generate(Solution). % labeling constrain([]). constrain([Column|Columns]) :- noattack(Column, Columns, 1), constrain(Columns). noattack(_, [], _). noattack(Column1, [Column2|Columns], Offset) :- Column1 ## Column2, % ίδια στήλη Column1 ## Column2 + Offset, % διαγώνιος ↘ Column1 ## Column2 - Offset, % διαγώνιος ↗ NewOffset is Offset + 1, noattack(Column1, Columns, NewOffset). generate([]). generate([Column|Columns]) :- indomain(Column), generate(Columns).
📝 Τι σημαίνουν τα σύμβολα
  • X :: 1..N — η X είναι μεταβλητή πεδίου με τιμές 1..N
  • X ## Y — περιορισμός: X ≠ Y
  • indomain(X) — μη-ντετερμινιστική εκχώρηση τιμής
💡 Γιατί τόσο γρήγορο

Όταν εκτελείται indomain(Column1), οι περιορισμοί Column1 ## Column2 εφαρμόζονται άμεσα και αφαιρούν αδύνατες τιμές από τα πεδία των επόμενων μεταβλητών. Αυτό λέγεται constraint propagation και κουρεύει εκθετικά τον χώρο αναζήτησης.

8.4 Εφαρμογές CLP

  • Κατασκευή ωρολογίων προγραμμάτων (πανεπιστήμια, νοσοκομεία)
  • Προγραμματισμός προσωπικού (shifts)
  • Σχεδίαση παραγωγής (job-shop scheduling — όπως η Εργ. 3!)
  • Διανομή αγαθών (vehicle routing)
  • Σχεδίαση κυκλωμάτων
📚 Σύνδεση με τη Εργ. 3 (job-shop)

Η Εργ. 3 (job-shop scheduling) είναι κλασικό CSP. Παρόλο που η εκφώνηση το ζητάει σε καθαρή Prolog, η στρατηγική είναι ταυτόσημη με CLP: εφάρμοσε τους περιορισμούς (deadline, πόροι) όσο το δυνατόν νωρίτερα. Αν τυχόν χρησιμοποιήσετε ECLiPSe, η λύση γίνεται πολύ απλούστερη και γρηγορότερη.

Στρατηγική για Άσκηση Υπολογισμού M_P

  1. Συγκέντρωσε σύμβολα P (κατηγορήματα), F (συναρτησιακά), V (μεταβλητές) από το πρόγραμμα
  2. Κατασκεύασε U_L από όλους τους πιθανούς ground όρους
  3. Κατασκεύασε B_L από όλους τους πιθανούς ground άτομα
  4. Εφάρμοσε T_P επανειλημμένα ξεκινώντας από ∅ μέχρι να μην προστίθεται τίποτα νέο
  5. Το αποτέλεσμα είναι το M_P
